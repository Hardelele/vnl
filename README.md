# VNL — язык описания нейронных микросхем

Исходник модели — текстовый файл `.vnl`. Он разбирается в IR, а IR компилируется
в разные бэкенды: быстрый точечный симулятор для интерактивной работы и скрипт
NetPyNE/NEURON для биофизики. Свой солвер уравнений Ходжкина–Хаксли не пишется
и писаться не будет.

```
   .vnl  ──►  AST  ──►  IR  ──┬──►  L1: точечный симулятор (чистый Python)
                              ├──►  L2: скрипт NetPyNE → NEURON
                              ├──►  HTML: схема (раскладка ELK), растр, трассы
                              ├──►  JSON ──► интерфейс (React, ui/)
                              └──►  граф в DOT
```

## Запуск

```bash
pip install -e .[dev]

vnl check  examples/ffi.vnl
vnl run    examples/ffi.vnl --traces out.csv
vnl view   examples/ffi.vnl --open          # схема, растр и трассы в браузере
vnl export examples/ffi.vnl -o ffi.netpyne.py
vnl graph  examples/disinhibition.vnl -o circuit.dot
```

`vnl view` собирает самодостаточную HTML-страницу из трёх блоков:

- **Схема** — морфология и точки контактов. Сигнал течёт слева направо:
  дендриты веером слева, аксон справа, кружок на ветви — место, куда сел
  контакт; пунктир — нейромодулятор.
- **Активность сети** — по дорожке на нейрон: штрихи спайков, под ними
  мембранный потенциал, серой полосой окно работы стимула. Обзорный экран,
  он растёт строками, а не уплотнением: новая клетка не отнимает место
  у остальных.
- **Записанные величины** — подробные графики, у каждого вида записи своя
  подача: у потенциала линия порога, у проводимости отсчёт от нуля
  и заливка, у веса — сколько было и сколько стало, у спайков — штрихи.

Временная ось на странице одна: тик «100 мс» в активности сети и в графиках
стоит на одной вертикали, поэтому блоки читаются друг под другом. Оформление
следует дизайн-системе Reckue (`design/reckue/`), светлая и тёмная темы.
Скриптов в странице нет, весь вывод — статический SVG и CSS.

### Раскладку считает ELK, а не мы

Расстановка клеток и разведение связей — отдельная задача, и решать её
вручную незачем: самописные кривые начинают сливаться уже на трёх контактах.
`vnl.layout` собирает граф с портами и отдаёт его
[ELK Layered](https://eclipse.dev/elk/) через Node; `vnl.report` только рисует
готовые ломаные. Порты с `FIXED_POS` — причина выбора именно ELK: они
позволяют привести связь ровно в ту точку дендрита, где объявлен контакт
(Graphviz с `splines=ortho` этого не умеет).

```bash
npm install --prefix tools/layout elkjs
```

Без Node и elkjs всё работает по-прежнему: раскладка падает на встроенную
послойную, и страница это отмечает. Движок выбирается флагом
`--layout elk|builtin|auto`. Зависимостей у ядра по-прежнему нет — ELK нужен
только для картинки.

`vnl run` на примере feed-forward inhibition:

```
IN ......|.|.|||||.||||.|.||||.|..||||||..|||.||.|....|.|.||||.|||.|....|.||.....
 E ...........|..|....|................|.....|...................|...............
 I ......||.||||||.||.|..||.||.|...||.||..||||||.|.....||.||||..||.|.....|||.....
   0                                                                      400 мс
```

## Интерфейс

`vnl view` даёт страницу-документ: её печатают, кладут в задачу, открывают без
всего. Там, где нужно разбираться в причинности, есть интерфейс — он живёт
в `ui/` и читает тот же прогон в виде JSON:

```bash
vnl data examples/ffi.vnl -o ui/public/run.json
cd ui && npm install && npm run dev
```

Первый экран — инспектор нейрона: входы с местом контакта и параметрами,
мембранный потенциал с порогом, возбуждение и торможение врозь, их баланс и
усреднённый отклик после спайка каждого входа. Курсор времени общий для всех
графиков, значения под ним держатся в шапке.

Собрано на Vite и React без Next: локальному инструменту не нужны ни SSR, ни
серверный роутинг, а один готовый прогон он читает файлом. Формат обмена
описан в `src/vnl/api.py`, его зеркало для TypeScript — в
`ui/src/model/types.ts`; менять их можно только вместе.

## Язык

```
morphology pyr {
    soma           len=20um  diam=20um
    dend.apical[3] len=200um diam=2um  lambda=250um
    axon           len=500um diam=1um
}

cell pyr_l5 : excitatory, glutamate {
    morphology = pyr
    tau_m      = 15ms
    threshold  = -50mV
    adaptation = 1.5mV
}

neuron E : pyr_l5
neuron I : pv

I.axon -> E.dend.apical[2]@0.72 {
    receptor   = gaba_a
    weight     = 1.6nS
    delay      = 1.4ms
    depression = { u = 0.3, tau_rec = 120ms }
    plasticity = stdp_rl { tau_eligibility = 500ms, modulator = dopamine }
}

modulator dopamine : dopamine from VTA { gain = 1.0  tau = 200ms }

stim drive -> IN.soma : poisson rate=250Hz weight=1.5nS start=20ms stop=380ms
record E.soma.v
run { dt = 0.1ms  duration = 400ms  level = L1  seed = 7 }
```

Числа пишутся с единицами (`ms`, `nS`, `um`, `mV`, `Hz`, `nA`); внутри IR всё
приводится к мс / нСм / мкм / мВ / Гц / нА.

### Два решения, на которых держится всё остальное

**Адресация контакта двухуровневая.** В исходнике стоит логический адрес
`E.dend.apical[2]@0.72`; резолвер превращает его в `(section, fraction)` — тот
самый кортеж, который понимают и NEURON (`sec(0.72)`), и NeuroML2
(`postSegmentId` + `postFractionAlong`). Логический адрес переживает смену
морфологии, разрешённый — нет, поэтому хранится первый.

**Обе стороны контакта — точки, а не клетки.** `pre` и `post` типизированы
одинаково, поэтому axo-axonic, axo-dendritic и axo-somatic контакты — один
механизм без спецслучаев.

### Ничего не теряется молча

При понижении уровня детализации параметры деградируют по явным правилам, и
каждое срабатывание попадает в отчёт:

```
деградация L2 -> L1:
  контакт c1: положение dend.apical[1]@0.6 (120 мкм от сомы) свёрнуто
  в вес x0.619 и задержку +0.60 мс
```

То же на экспорте: `vnl export` печатает список того, что NetPyNE не принимает
один в один (короткотечная динамика, сигнал нейромодулятора, остановка NetStim).
Экспорт — это «скрипт плюс список потерь», а не молчаливое усечение модели.

## Примеры

| Файл | Что показывает |
|---|---|
| `examples/ffi.vnl` | feed-forward inhibition; выход пирамиды падает с 13 спайков до 6 |
| `examples/disinhibition.vnl` | VIP → SST → PYR; вес пластичного входа стоит на месте до дофамина и растёт после |
| `examples/depression.vnl` | один и тот же вход на депрессирующий и фасилитирующий контакт |

Записывать можно `v` (потенциал), `g` (суммарная проводимость), `g_exc`
и `g_inh` (возбуждение и торможение врозь — в сумме их баланс пропадает),
`w` (суммарный вес пластичных входов) и `spikes`.

## Что уже есть

- разбор `.vnl`, диагностика с указанием места и причины;
- морфология, логическая адресация, затухание и задержка по дендриту;
- L1: LIF с адаптацией, проводимостные синапсы, задержки, короткотечная
  динамика Цодыкса–Маркрама, парный STDP, STDP с подкреплением и модулятором;
- экспорт в NetPyNE со списком потерь;
- визуальный отчёт `vnl view` с раскладкой через ELK и граф в DOT;
- интерфейс на React: инспектор нейрона с общим курсором времени;
- 68 тестов у ядра и 17 у интерфейса, зависимостей у ядра по-прежнему нет.

## Чего ещё нет

- **L2 не прогонялся.** Генератор NetPyNE проверен только на то, что скрипт
  компилируется и несёт правильные `sec`/`loc`. NEURON локально не стоит;
  первый настоящий прогон нужно делать в WSL или Docker.
- **Нормировка проводимости условная.** Вес в `nS` трактуется в единицах
  проводимости утечки (leak = 1 нСм), поэтому веса в примерах подобраны под
  L1, а не взяты из физиологии. При первом прогоне L2 масштаб придётся
  пересчитать — это ожидаемая правка, а не сюрприз.
- Страница `vnl view` только показывает: редактировать схему мышью нельзя,
  и нет курсора времени, который вёл бы по всем дорожкам сразу и подсвечивал
  состояние схемы, — для этого нужен скрипт на странице.
- В интерфейсе пока только инспектор: схема и активность сети остаются
  в статической странице и ещё не переехали.
- Усреднённый отклик показывает корреляцию, а не действие входа поодиночке:
  если два источника спайкуют синхронно, в окне каждого виден и сосед.
- Дендритный веер рисуется схематично и в раскладке участвует лишь габаритом:
  ELK обходит прямоугольник клетки, а не саму ветвь.
- Нет импорта `.swc`, экспорта в NeuroML2, редактора и L0.
