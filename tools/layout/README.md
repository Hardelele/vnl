# Раскладка схемы

`vnl view` умеет раскладывать схему через [ELK Layered](https://eclipse.dev/elk/).
Движок нужен, чтобы не изобретать расстановку узлов и разведение связей:
ELK поддерживает порты с фиксированной позицией, а значит связь приходит
ровно в ту точку дендрита, где объявлен контакт.

```bash
npm install --prefix tools/layout elkjs
```

Без этого `vnl view` работает по-прежнему: раскладка падает на встроенную
послойную, а страница помечает это в отчёте. Движок выбирается флагом
`--layout elk|builtin|auto` (по умолчанию `auto`).
