# Макеты MVP

Экспорт из Claude Design Canvas. Открывается файлом в браузере: разметка
декларативная (`sc-if`, `sc-for`, `{{ }}`), поэтому читать её можно и глазами,
и в браузере — второе честнее, часть состояний в тексте не видна.

| Файл | Что в нём |
|---|---|
| `Page MVP.dc.html` | библиотека, карточка паттерна, песочница — экраны задач #477–#481 |
| `Spike Timeline.dc.html` | общий таймлайн: растр спайков и трассы (#480) |
| `Spike Timeline Variants.dc.html` | варианты подачи того же таймлайна |

`uploads/` — образцы, на которые опирался макет: страница прогона и инспектор
из `docs/img`, плюс эталон тёмной темы для таймлайна.

`_ds/` — снимок дизайн-системы Reckue, который экспорт таскает с собой, чтобы
открываться без репозитория. Токены в нём совпадают с `design/reckue/tokens`
байт в байт; источник правды — по-прежнему `design/reckue`, и код читает
переменные оттуда. Если снимок однажды разойдётся с ним, прав `design/reckue`.

Макет — это спецификация, а не эталон вёрстки: он нарисован в собственных
компонентах Claude DS, а интерфейс собран на своих и на токенах Reckue.
Расхождения, сделанные сознательно, отмечены в коде рядом с местом.
